# Talking-head Reel

**Target:** 9:16, 1080×1920, 30 FPS unless source/delivery requires otherwise; 30–60 seconds as a starting target.

**Inputs:** one or more talking-head clips, optional narration/B-roll/logo/music, caption language and visual preset.

**Edit sequence:** inspect media; transcribe only when useful; mark false starts and recording errors; preserve natural pauses and emphasis; choose a truthful hook; reframe within vertical safe zones; add reviewed captions; use punch-ins only at meaningful emphasis points; place relevant B-roll only when available; mix music below speech; preview, inspect and validate.

**Deliverables:** final vertical MP4, SRT/VTT when requested and editable project manifest.
