# Design systems

A preset is a versioned visual system. It should control color, typography, grid, safe zones, captions, motion, transitions and audio treatment.

Available starter presets: Tech Editorial, Swiss Minimal, Cinematic, Creator Bold, Neo-Brutalist, Luxury Editorial and Retro Analog. See `presets/*.json`.

To add a preset: copy the closest JSON, use a unique kebab-case identifier, keep values portable/serializable, bundle no unlicensed font/media files, add a README entry and preview, then validate JSON.
