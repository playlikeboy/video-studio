01 / Capabilities

A complete post-production loop.

The Skill coordinates the edit. Proven tools do the media processing. You stay in control of source files, optional dependencies and final delivery.

01 — EDIT

Real media operations

Trim, split, join, crop, resize, retime, stabilize, mix audio, caption, reframe and export.

02 — STORY

Intentional storytelling

Build hooks and payoffs, tighten dead air without flattening personality, and create platform-specific versions.

03 — MOTION

Reusable motion systems

Typography, layouts, lower thirds, UI animation, transitions and design presets that stay consistent.

04 — INTELLIGENCE

Transcript and scene aware

Opt into transcription, word alignment, silence analysis and scene detection only when the brief benefits.

05 — SPEED

Fast iteration

Stream-copy when valid, cache analysis, preview with proxies, bound parallel tasks and avoid repeated lossy encodes.

06 — VERIFY

Quality before delivery

Check codecs, duration, frame rate, captions, crop, sync and representative frames. A zero exit code is not proof of a good video.

02 / Installation

Start lean. Add power when you need it.

One Python command installs the existing Video Studio Skill, then asks—one by one—whether you want optional editors, renderers and analysis tools. Every optional answer defaults to No.

Interactive installation

Python 3.10+ · macOS, Linux and Windows · no installer dependencies.

1
Clone the repositoryGet the Skill, references, presets, docs and installer.
git clone https://github.com/playlikeboy/video-studio.git cd video-studio python3 scripts/install.py
2
Choose the install scopePersonal Claude Code skills or one project's .claude/skills directory.
3
Choose optional integrationsHyperFrames? FableCut? Remotion? Transcription? Skip any or all.
Only skills/video-studio/ is copied. The source Skill is not rewritten, unrelated installed files are preserved, and existing Skill files are not updated unless you approve.

Core media requirement: FFmpeg

FFmpeg and FFprobe handle media probing, editing and rendering. The installer checks for them but never silently installs system packages.

brew install ffmpeg
sudo apt install ffmpeg

Debian / Ubuntu. Other distributions use their own package manager and configured codec repositories.

winget install ffmpeg

Reopen the terminal after installation so PATH updates are available.

ffmpeg -version ffprobe -version

HyperFrames additionally needs Node.js 22+. FableCut needs Node.js 18+ and Chromium. Neither is required for the base Skill.

Choose optional integrations

Select only what you want. The command below installs the core Skill plus exactly these choices. The installer will still ask for personal or project scope.

python3 scripts/install.py

No add-ons selected. This installs the core Skill only.

Python tools install into separate user-level virtual environments. Remotion is scaffolded separately. WhisperX can download several gigabytes. The bundled Video Studio Skill is left untouched.

04 / Production system

From raw footage to a deliberate cut.

An inspectable workflow that protects source media and makes quality measurable.

01 / DISCOVERInspect media

Probe codecs, streams, duration, frame rate and workspace boundaries.

02 / DECIDEPlan the edit

Build edit decisions, story beats and one coherent design system.

03 / CREATEExecute locally

Use installed tools, proxies, cached analysis and reversible outputs.

04 / VERIFYReview and deliver

Inspect frames, listen to audio, validate captions and probe exports.
