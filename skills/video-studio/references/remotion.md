# Remotion integration

Remotion is an optional React-based renderer for compositions that benefit from React components, parameterized data or an existing React asset system.

Official website: https://www.remotion.dev/
Repository: https://github.com/remotion-dev/remotion

Use it when the project already uses React components, data-driven sequences need reusable component logic, React ecosystem integrations are important or the user has an existing Remotion project. Prefer HyperFrames for HTML/CSS-native motion workflows where it already offers the needed capabilities.

Check current Remotion documentation and installed version. Reuse existing compositions and transition packages. Keep props serializable. Render low-resolution previews for iteration. Validate frame count, FPS, dimensions and audio after render.

Remotion has specific licensing terms, including company-size and usage conditions. Review current official licensing before bundling or recommending it to an organization.
