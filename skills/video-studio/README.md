# Video Studio Claude Skill

Copy this entire directory into `.claude/skills/video-studio/` in a project or into your personal Claude Code skills directory. The entry point is `SKILL.md`; task-specific guidance is in `references/`. The skill expects the repository-level `presets/` and `templates/` as optional companion assets. If you install only this folder, copy those two directories alongside it or adjust the references to your workspace.
