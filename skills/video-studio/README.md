# Video Studio Claude Skill

Copy this entire directory into `.claude/skills/video-studio/` in a project or into your personal Claude Code skills directory. `SKILL.md` is the required entry point; task-specific guidance lives in `references/`.

The repository-level `presets/` and `templates/` directories are optional companion assets. When installing the skill into another project, copy those directories to that project root if you want the starter design systems and production blueprints available.
