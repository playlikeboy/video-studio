# Design presets

Each preset is a small, versioned JSON file. It describes visual language; it does not by itself guarantee a finished template.

- `tech-editorial.json`
- `swiss-minimal.json`
- `cinematic.json`
- `creator-bold.json`
- `neo-brutalist.json`
- `luxury-editorial.json`
- `retro-analog.json`

Presets must not bundle unlicensed fonts, music or footage. Font names are suggestions; check local availability and language coverage.
